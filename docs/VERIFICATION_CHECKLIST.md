# 검증 체크리스트 (사실성 관리)

이 문서는 포트폴리오·이력서에 쓰인 수치·주장 중 **외부에서 즉시 검증되지 않는 항목**과
그 처리 방식을 기록한다. 목적은 채용담당자가 근거를 물었을 때 지원자가 즉시 답할 수 있게
하고, 근거 없는 과장을 웹에서 배제하는 것.

범례: ✅ 웹 표기 유지(근거 각주 있음) · ⚠️ 웹 표기 유지하되 사용자 재확인 필요 · ❌ 웹에서 제거

## 도메인 표기 원칙

- K-POP·댄스 직접 경험 **없음** → 만들지 않음.
- Show(X)의 실내 행사 운영 경험만으로 "오프라인 공간·참가자 동선·현장 관찰" 연결.

## 인쇄(PDF) 레이아웃 — 확인 결과 (2026-08-06)

- 벡터 텍스트(선택·검색·ATS 파싱 가능), nav·footer·버튼 인쇄 시 숨김 ✓
- 전화번호·이메일·GitHub URL 인쇄물에 표시 ✓ (전화번호는 화면 숨김·인쇄 노출)
- 프로젝트 카드 `page-break-avoid`로 중간 잘림 없음 ✓
- 한국어 글꼴(Pretendard) 정상 ✓
- **길이**: 기본/FODI 이력서 모두 약 4페이지. 목표의 "2페이지 이내 우선"보다 김.
  - 이유: 프로젝트마다 P/A/R 3줄 + 스택 + 카테고리 스킬 표 + 교육 5 + 성과 5.
  - FODI 프로필은 프로젝트를 5→4로 이미 축소. 추가 2페이지 축약은 P/A/R 근거를 덜어내야 해
    사실성·설득력과 상충 → 웹 포트폴리오/FODI 페이지가 깊이를 담당하고 PDF는 요약 첨부로 운용.
  - 사용자 판단 필요: 2페이지 강제(성과 각주·교육 세부 축약)를 원하면 추가 축약 가능.
